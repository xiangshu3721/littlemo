# 小程序合规上线闸门

此文区分已落地的产品操作、仍需运营主体确认的事实，以及必须由运营主体处理的外部程序。页面和代码不等于法律审查或监管备案完成。

## 已落地到代码

- 登录前展示服务协议、隐私政策、运营主体、适用年龄和数据流摘要；用户须勾选同意，并确认已满 18 周岁。服务端记录协议版本、同意时间和成人年龄确认时间。当前版本服务端只接受 `LEGAL_AGE_SCOPE=仅限年满18周岁`；运营主体、联系渠道、云端地区/期限及小程序备案等公开披露未完整时，前后端都拒绝注册。
- 对情绪日记、心理状态、聊天及洞察中可能出现的敏感个人信息，登录前单独展示处理目的、必要性、影响和拒绝后果，使用独立勾选并记录单独同意版本/时间；用户可单独撤回，后续相关功能停用但既有记录不自动删除；有效会话仍可进入隐私中心导出、撤回 AI 同意和注销。
- 第一次发送聊天、请求深度洞察或阶段分析前，单独展示模型、模型备案、数据处理区域、留存/优化规则；须另行同意。服务端按同意版本拦截未同意请求，并允许撤回后续 AI 处理同意。
- 对话页声明正在与 AI 互动，生成内容标注“AI 生成”，不再要求模型隐瞒 AI 身份；用户在对话页连续可见使用累计超过两小时会看到休息提醒。
- 隐私中心提供账号数据副本、撤回 AI 同意、注销账号和删除业务数据库记录、隐私联系/投诉入口、微信隐私指引以及 120 / 110 / 12356 求助入口。
- 数据副本包含账号标识、昵称头像、服务端记录和本机日记缓存；不包含聊天图片原图。账号注销同时删除本机 `littlemo.*` 缓存、应用保存的聊天图片以及已知头像/导出文件。
- 相册隐私授权异常时不再放行；主动设置的头像会上传账号云端，聊天图片原图留在本机。

## 上传前必须补齐的事实

根 `.env.production` 和小程序构建用 `apps/miniapp/.env.production` 均需填写同一组公开字段。构建脚本会拒绝缺失值、占位符和非成人服务范围；不要把 DeepSeek 密钥或 JWT 密钥写入小程序配置。

| 项目 | 必须由运营主体确认 |
| --- | --- |
| 经营者 | 运营主体全称、个人信息保护联系渠道、投诉举报渠道及真实反馈时限 |
| 年龄 | 是否只面向成年人、如何核实年龄、未成年人申诉和误判处理。当前只有“我已年满18周岁”自我确认，不是实名年龄核验；不得据此宣称已验证年龄 |
| 敏感信息 | 由运营主体/隐私顾问核实情绪、心理状态记录的敏感个人信息分类、必要性评估、保护措施及个人信息保护影响评估；当前代码提供独立说明和同意留痕，不代表评估或安全措施已完成 |
| 监护/紧急联系人 | 哪些情况下确有必要、如何取得单独同意、谁可以访问、保存多久、撤回/更换方式。当前没有采集或联络监护人/紧急联系人的能力 |
| AI 服务 | 实际 `DEEPSEEK_MODEL`、适用的 DeepSeek Open Platform/API 合同、文本/上下文留存、是否用于模型优化、处理地域，以及准确的服务和算法备案信息 |
| 云端数据 | CloudBase/PostgreSQL 实际地域、生产访问权限、备份和网络日志保留期限、注销后各副本清除时限 |
| 备案编号 | 小程序备案编号 `MINIPROGRAM_FILING_NO`；完成后按主管部门/微信要求展示 |
| 微信后台 | 用户隐私保护指引与实际 API/字段逐项一致，声明头像上传、相册/相机调用、账号云端对话日记、AI 数据处理和数据管理能力 |

在服务器与小程序包内同步配置上述字段后，版本更新或数据处理方/模型/数据用途变化时要重新评估并递增服务协议、隐私政策或 AI 同意版本。仅改环境变量不等于取得既有用户的新同意。

## 当前仍阻断发布的运营与安全工作

1. 本产品持续提供情绪陪伴。从产品描述判断，高度可能属于《人工智能拟人化互动服务管理暂行办法》定义范围；这是基于现有功能的推论，适用性由运营主体和专业顾问最终确认。该办法已于 2026-07-15 施行。运营主体需完成适用的上线安全评估并向所在地省级网信部门提交报告，确认算法备案/变更流程，并保存评估材料。
2. 当前危机识别是关键词规则，只显示建议求助热线；没有经过验证的危机处置团队、人工升级/响应时限、紧急联系人通道或真实世界安全确认。它不构成全天候监护或自动救援。需要建立、演练并记录安全风险识别、申诉、重大风险限制/停止服务、投诉举报受理和反馈流程；在完成前不要宣称已具备这些能力。
3. 当前客户端不含未成年人模式、监护人流程、定期现实提醒、时长限制、分龄安全设置或年龄核验服务。脚本只允许运营范围声明为 18+，且前端自我确认不能替代年龄识别。若希望服务未成年人，必须先停止当前成人版发布路径，完成产品和服务端保护机制。
4. 12356 是国家统一心理援助热线；各地接通和服务时段由当地实际运营情况决定。应在目标地区真机确认拨号可达，并确保文案不承诺平台能接通、代拨或提供真人服务。
5. 需要核对本项目对应的小程序备案、主体、类目、名称和内容与微信后台完全一致。当前字段填入编号不代表已完成备案或微信审核。
6. 需要用真实账号完成授权拒绝、AI 同意/拒绝/撤回、导出、退出与注销、删除后重登、微信隐私指引、投诉渠道、危机提示和两小时提醒真机验收；并验证数据库级联删除、备份生命周期和 DeepSeek API 实际数据处理条款。

## 依据与边界

- 《人工智能拟人化互动服务管理暂行办法》适用于模拟自然人人格和沟通风格、提供持续情感陪伴/支持的服务；包含用户年龄/监护或紧急联系人、安全处置、未成年人保护、交互数据复制删除、AI 身份标识、超过两小时提醒、申诉投诉机制和上线安全评估等条款：[中国网信网全文](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)。
- 工信部移动互联网应用程序备案通知明确分发平台范围包括小程序：[工信部通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)。
- 情绪、心理或健康相关记录可能涉及敏感个人信息。具体类别和单独同意义务需结合真实数据流程评估；不得从“用户同意了整份政策”推导出所有敏感处理都已满足要求：[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。
- 12356 的统一号码由国家卫生健康委公布；是否可接通仍以用户所在地热线实际服务为准：[国家卫生健康委通知](https://www.nhc.gov.cn/yzygj/c100068/202412/49a1a65386cd4be582d4702fd0926ee8.shtml)。
