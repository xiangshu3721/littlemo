# 微信小程序提审配置（控制台）

代码侧已支持：未登录可浏览、登录前勾选协议、微信隐私授权按钮、AI 生成标识、免责声明、投诉反馈、账号注销。以下必须在微信公众平台 / CloudBase 由管理员完成（无开放接口可代填隐私指引与类目）。

## 服务类目（推荐）

不要选「医疗 / 心理咨询」。建议：

- 工具 → 信息查询，或
- 社交 → 笔记

简介示例：

> 有点情绪：用对话记下这一刻的心情，并生成日记与阶段回顾。回复由人工智能生成，仅供记录，不是心理咨询或医疗建议。

## 用户隐私保护指引（勾选）

在 MP 后台「设置 → 服务内容声明 → 用户隐私保护指引」新增并发布，至少勾选：

| 类型 | 用途文案（可直接粘贴） |
| --- | --- |
| 微信昵称 | 用于在「我的」展示和保存在你的账号资料 |
| 微信头像 | 用于在「我的」展示和保存在你的账号资料 |
| 选中的照片或视频 | 把相册里的照片放进对话或换成头像；聊天配图留在本机 |
| 摄像头 | 拍摄此刻的照片放进对话或换成头像 |
| 其他用户信息 / 内容信息 | 你发送的文字、陪伴对话、情绪日记和阶段回顾，存在云端账号，并发送到服务器上的人工智能接口以生成回复与回顾 |

收集方式：用户使用过程中。存储：云端账号，注销后删除。

发布隐私指引后，小程序内「隐私保护指引」会打开微信官方文本。

## CloudBase（可用密钥代操作）

把下列变量交给本仓库的生产环境（不要提交 git）：

- `CLOUDBASE_ENV_ID`
- `TENCENTCLOUD_SECRET_ID`
- `TENCENTCLOUD_SECRET_KEY`
- `DATABASE_URL`
- `JWT_SECRET`（≥32 字符）
- `DEEPSEEK_API_KEY`

然后可跑：

```bash
./scripts/apply-cloudbase-env.sh
./scripts/build-miniapp-prod.sh
```

云托管服务名必须是 `littlemo-api`，端口 `3000`，开启身份认证。部署后执行 `npm run db:deploy`。

## 上传与提审

1. `CLOUDBASE_ENV_ID=… ./scripts/build-miniapp-prod.sh`
2. 微信开发者工具打开 `apps/miniapp`，确认未勾选「不校验合法域名」
3. 上传；审核说明写：免费用、无支付、可先浏览再登录、AI 陪伴记录、测试请用审核员自己的微信

生成式人工智能若主体需要算法备案，在工信/网信完成后再提审。本仓库无法代办备案号申请。
